Troubleshooting

Find your problem below. Most fixes take a minute. If you're still stuck, create a support bundle and send it to your admin.

Phone and audio

Calls and sound

The status pill stays orange or says Offline
  • Click Register in the top bar. CallBridge only connects after you do.
  • Check the SIP server, username, and password in Settings → SIP. The password is the extension's SIP secret, not your voicemail PIN.
  • Match the Transport to your provider. HivePBX extensions accept UDP only; choosing the Axion / HivePBX provider sets this for you.
  • Make sure no other softphone or desk phone is fighting for the same extension on this network.
I can't hear the caller, or they can't hear me
  • Settings → Audio: confirm the headset is chosen for both Microphone and Speaker, then use Test microphone and Test speaker.
  • If you plugged the headset in after opening CallBridge, click Refresh devices.
  • Check that Mute isn't on during the call.
  • Windows Settings → Privacy & security → Microphone: allow desktop apps to use the microphone.
Incoming calls don't ring
  • CallBridge must be running. Look for its icon in the system tray. Turn on Launch when I sign in to Windows in Settings → Sign-in.
  • Settings → Audio → Ringtone plays on: choose a speaker you can hear, then Test ringtone.
  • Windows Focus assist or Do not disturb can hide the notification. The incoming call window still appears.
The Voicemail card says "Waiting for status"

The phone must be registered first. Then check Settings → Phone account → Voicemail access code (HivePBX: *97). Some phone systems only send voicemail status after the first new message, so leave yourself a test voicemail.

Call parking shows "No park slots set up"

Settings → Phone account → Park slots: enter the slot numbers, such as 4389 or 701-705. Put the code that parks a call in Park code instead, for example HivePBX's 4388. Don't list the park code as a slot.

ConnectWise

Tickets and callers

A customer calls but shows as an unknown number
  • Settings → ConnectWise → Sync ConnectWise contacts to refresh the directory. New ConnectWise contacts don't appear until you sync.
  • The contact needs a phone number in ConnectWise that matches the number they're calling from, such as their mobile.
  • On ConnectWise Platform, only each company's main number and primary contact's number can match. Add other callers with Import CSV or Add contact, or use Platform, with PSA contact lookup.
"Ticket creation failed" or a ticket takes a long time

ConnectWise can take a minute or more to create a ticket while it runs board workflows and email notifications. CallBridge waits up to 2 minutes. If ConnectWise still doesn't answer, CallBridge checks whether the ticket was created anyway before reporting a problem.

Before trying again, look in ConnectWise for a new "Phone support" ticket on that company, so you don't create a duplicate. If creation is always slow, ask your admin to review the board's workflow rules.

"Connect ConnectWise in Settings first"

The chosen Ticketing connection isn't fully set up. For PSA, fill in every field on the PSA API member card and click Test PSA. For Platform, enter the client ID and secret and click Test Platform. Then save.

"Ask your admin to choose a default service board"

New tickets need somewhere to go. For PSA, enter the Default service board ID. For Platform, click Load boards and sources, pick a board and a source, and save.

ConnectWise PSA test fails with 401 or 403
  • 401: the Site URL, Company ID, public key, or private key is wrong. Private keys can't be viewed again; generate a new key pair if unsure.
  • 403: the API member's security role is missing permissions. It needs to read companies, contacts, and service tickets, create tickets and notes, create time entries, and add and edit contacts (used to save callers' numbers).
  • Make sure the Client ID is filled in. ConnectWise rejects requests without one.
ConnectWise Platform test fails
  • 401: check the client ID, secret, and that you picked the right region.
  • 403: the API access is missing scopes. It needs Tickets Read, Create, and Update, and Companies Read.
  • 423 Locked: too many sign-ins in a short time. Wait for the current token to expire (up to an hour) and try again.
"Time wasn't saved" or no time entry draft appears
  • A draft only appears after a connected call where a ticket was picked.
  • PSA time entries need Your member ID in Settings → Sign-in, and it must match your ConnectWise username exactly.
  • On Platform tickets there are no time entries. The minutes are saved as an internal note on the ticket instead.
Open ticket in ConnectWise does nothing on Platform

ConnectWise's Platform API doesn't provide ticket web links, so CallBridge shows the ticket number instead. Search for that number in ConnectWise.

Does CallBridge work with ConnectWise RMM?

Not directly. There is no RMM setting. Tickets that RMM creates in PSA or Platform, like patching and device alerts, appear in the incoming call window with the customer's other open tickets.

The app

Install, updates, and settings

I can't change phone or ConnectWise settings

Those tabs are locked with an admin PIN. Ask your admin, or click the locked tab and enter the PIN. After too many wrong PINs, CallBridge makes you wait before trying again.

The update won't install
  • Updates install for everyone on the computer, so Windows asks for admin approval. If you aren't an admin, ask your IT team to approve it or push the MSI.
  • Updates wait until you're not on a call.
  • "Didn't match its published checksum" means the download was damaged or tampered with. CallBridge refuses it; try again later.
The Start menu or taskbar icon is blank

Install v0.15.2 or later, which fixes the icon. If it's still blank, Windows is showing a cached icon: unpin and re-pin CallBridge, or sign out of Windows and back in.

Where's CallBridge when I close the window?

Still running in the system tray, so calls keep ringing. Click the tray icon to open it; right-click to quit.

Still stuck? Send a support bundle.

Settings → Sign-in → Create support bundle saves a ZIP with version, settings status, and recent startup events. Passwords, keys, phone numbers, email addresses, and file paths are removed before it's written.
